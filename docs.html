Points de Terminaison (REST API Endpoints)

L'API permet d'interroger par programmation l'ensemble du référentiel taxonomique, les matrices de traits continus harmonisés, les simulations éco-climatiques CMIP6 et les données d'enquêtes terrain sous format JSON normalisé.

GET /api/v1/taxa
Liste complète des taxons répertoriés

Paramètres de requête : family (string), iucn_status (string), limit (int, default: 50)

{
  "total": 15,
  "items": [
    {
      "id": "balanites_aegyptiaca",
      "scientific_name": "Balanites aegyptiaca (L.) Delile",
      "family": "Zygophyllaceae",
      "gbif_key": 3189912,
      "vernacular_moore": "Kieglga"
    }
  ]
}
GET /api/v1/traits/{species_id}
Matrice des 8 traits fonctionnels continus 
{
  "species_id": "balanites_aegyptiaca",
  "traits": {
    "sla_mm2mg": 11.2,
    "ldmc_mgg": 378.0,
    "wood_density_gcm3": 0.69,
    "p50_hydraulic_mpa": -4.2,
    "seed_mass_mg": 2840.0,
    "drought_index": 92.0
  }
}
POST /api/v1/climate/simulate
Moteur de simulation éco-climatique CMIP6

Corps de la requête (JSON Payload) :

{
  "species_id": "balanites_aegyptiaca",
  "scenario": "ssp245",
  "horizon": 2050,
  "delta_temp_c": 2.4,
  "delta_precip_pct": -12.0
}

Dictionnaire des Variables & Unités Scientifiques

Variable Nom Complet & Définition Unité Standard Protocole de Mesure
SLA Surface Foliaire Spécifique (Specific Leaf Area) mm² / mg Scanner foliaire + étuve 70°C / 48h (Pérez-Harguindeguy et al., 2013)
LDMC Teneur en Matière Sèche Foliaire (Leaf Dry Matter Content) mg / g Masse sèche divisée par la masse saturée d'eau
WD Densité Basale du Bois (Wood Density) g / cm³ Sondage à la tarière de Pressler (masse sèche / volume vert)
P50 Vulnérabilité à la cavitation hydraulique MPa Courbe de vulnérabilité par cytométrie / chambre à pression de Scholander
